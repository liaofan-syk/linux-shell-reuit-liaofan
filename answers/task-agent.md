# 任务2
1. Agent为什么能够读取文件、修改代码，而普通聊天AI通常不能？
普通聊天AI只具备文本对话能力，没有操作本地文件系统的权限；Agent有工具调用能力，可以读取、编辑本地电脑上的文件，在打开的代码仓库内操作文件。
2. Tool 在 Agent 中起到了什么作用？
Tool就是Agent可以调用的工具。依靠Tool，Agent突破纯文本对话限制，可以真实读写文件、执行命令，完成实操任务。没有Tool，Agent和普通对话AI没有区别。
3. 为什么项目需要给 Agent 配置一份类似“员工手册”的规则？
用来约束Agent行为，明确允许操作和禁止操作的范围，例如禁止删除作业文件、只能修改指定文件，防止Agent误删、乱改项目代码，保证操作可控。
4. Agent为什么可能“忘记”之前说过的内容？Agent的额度怎么计算？
Agent存在上下文窗口上限，对话历史、代码内容不断累积，超出窗口容量时，最早的内容会被截断，表现为“忘记”。
5. 如果一个 Agent 可以随便执行任何终端命令，会有什么风险？
风险很高：可以删除本地文件、篡改项目源码，读取电脑里的隐私文件；一旦执行破坏性指令，会直接损坏整个项目甚至系统文件。
